# Traceability matrix template

One table from the client's request to a test idea. Nobody but you sees the full chain: this is the analyst's contribution.

| Request (Source) | Requirement / rule | AC | Design (Figma frame) | Test idea | Status |
|---|---|---|---|---|---|
| issue #__ "Original request", sentence 1 | RULE-01 | AC-01, AC-02 | frame "…" | | Draft / Agreed / Open Q-__ |

Statuses: **Draft** (AI/your draft), **Agreed** (agreed with the client, with date and who), **Open** (depends on question Q-##).

**Check:** every "Request" row has at least one requirement; every requirement has an AC; every AC has a test idea; no orphans (a RULE without a request or an AC without a rule).
