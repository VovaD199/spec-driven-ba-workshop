## Частина 2. Пілот (1-2 люди, бажано нетехнічні)

Мета: перевірити **час** і **зрозумілість**, а не знання. Одна людина без досвіду з Git (профіль новачка), друга з досвідом (профіль швидкої доріжки).

### Підготовка

- [ ] Дати пілотам лише PDF (`python3 tools/build_materials.py --all --pdf`) і посилання на шаблон; **не підказувати**.
- [ ] Домовитися про спосіб зв'язку, де пілот пише, коли застряг; фіксувати, **за скільки хвилин** він написав.
- [ ] Підготувати обліковий акаунт Figma або посилання ментора для Figma.
- [ ] Ментор виконує роль замовника у Дні 2 за `mentor/uk/day-2-stakeholder-script.md`.
- [ ] Один спостерігач веде таблицю нижче.

### Таблиця спостережень (по дню)

|---|---|---|---|---|---|---|
| | | | | | | |

### Критерії успіху пілоту

1. Профіль новачка проходить кожен день у межах 240 хв **базової доріжки** (із 30-хвилинним запасом Дня 4) і здає PR.
2. Жодного кроку, на якому пілот застряг понад 20 хв без fallback.
3. Усі команди спрацювали або виправлені в джерелах.
4. Профіль швидкої доріжки вкладається в день зі стретч-завданнями або без них; зафіксувати, скільки стретч-завдань зроблено.
5. Пілот сам відповідає на питання «що ти зробив своїм» (власні правки видно в PR).

### Після пілоту

- [ ] Перенести знахідки в таблицю «Знахідки» вище й виправити джерела (`materials/`, `templates/`, `fallback/`).
- [ ] Оновити хронометраж у блоках «Для ментора».
- [ ] Записати висновки пілоту (що змінено й чому) у `docs/plan.md` або новий `docs/decisions.md`.
- [ ] Перегенерувати PDF, оновити Moodle-курс-пісочницю.

## Що я не можу зробити сам

Встановлення на Windows і macOS, Cursor із чатом, Figma Make і Figma MCP, Moodle, а також пілот із людьми: потрібні ви або ментор. Усе інше (виправлення текстів, перегенерація PDF, оновлення прикладів за знахідками) можна передати на виконання після заповнення таблиць.
