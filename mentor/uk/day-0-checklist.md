# Чекліст ментора: День 0

- [ ] Розіслати студентам `materials/uk/day-0/day-0-prepare.md` за 5-7 днів до Дня 1.
- [ ] Зібрати скріншоти `git --version` / `node -v`; хто не надіслав, нагадати за 2 дні.
- [ ] Окремо запитати, хто не має прав встановлення, акаунта GitHub чи Figma (для Figma підготувати посилання на макет).
- [ ] Перевірити на чистій Windows: `winget` (Git, Node LTS, GitHub.cli).
- [ ] macOS: зібрати відгуки про `xcode-select`, `brew`, `node@22`.
- [ ] Linux: підтвердити підтримувані дистрибутиви.
- [ ] Перевірити, чи доступний GitHub Codespaces для зовнішніх учасників.
- [ ] Перевірити актуальність версії nvm (v0.40.1) у installation-guide.
- [ ] Політика: на одну проблему встановлення студент витрачає ≤20 хв, потім пише ментору.
