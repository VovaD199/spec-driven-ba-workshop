# Specification (DRAFT, awaiting approval)

## Goal
A ready-to-run 4-day course (4 h/day) teaching business analysts and PMs to practice Spec-Driven Development with AI (Cursor), using BA strengths: elicitation, requirements quality, traceability, handoff.

## Audience
BA/PM from junior to junior+. Two tracks per day: **Base** (novice-safe, step-by-step, fallbacks) and **Fast** (stretch tasks for strong students).

## Requirements
- R1 Each day fits 240 min on the Base track, with time budget per block.
- R2 Every command, path and link is verified; no `course/` vs `materials/` mismatches; automated link check.
- R3 Pre-course Day 0: install, GitHub authentication, glossary, environment check.
- R4 Figma is mandatory. If a student has no account, they work from a mentor-provided link/file. Figma MCP setup has a no-account fallback and time budget inside the course hours.
- R5 End-to-end BA line: stakeholder simulation, "why" behind requirements, NFR (privacy/security), human verification of requirements, traceability from source requirement to test, closing loop requirement -> code -> test.
- R6 AI hallucination control: labels (Grounded/Inferred/Invented) set by the student; sources checked.
- R7 Full mentor guide: minute-by-minute scripts, risks and plan B, FAQ with links to official docs, lag indicators, limits policy, grading criteria.
- R8 Single source of truth in Markdown; PDF/Moodle generated by script.
- R9 Bilingual UK/EN with the same structure and IDs.
- R10 Learning goal -> step -> verification mapping table.

## Out of scope
The lf-client application itself.

## Acceptance
Clean run-through of Days 0-4 by a new person within time; zero broken links; mentor guide covers 100% of days.

## Open questions

- Figma plan limits (MCP call quota) for groups.
